# メルカリ手残り計算機 (Mercari Profit Calculator)

メルカリで不用品を出品する際に、**手残り金額（純利益）の計算**および**目標利益からの必要出品価格の逆算**ができる軽量・高機能なWebアプリケーションです。

PCブラウザだけでなく、スマートフォン（iPhone Safari / Android Chrome）での利用に最適化されています。

## 主な機能

- **出品価格 ⇄ 目標手残りの双方向自動計算**:
  - 販売価格を入力すると手残り金額と利益率をリアルタイム算出
  - 目標手残りを入力すると必要な出品価格を自動逆算（メルカリの10%手数料切り捨て仕様に対応）
  - よく使う価格帯（¥300, ¥500, ¥1,000, ¥2,000, ¥3,000, ¥5,000）のワンタップ入力チップ
- **不用品出品に合わせた配送サイズ・方法プリセット**:
  - 小型（ネコポス、ゆうパケットポストmini、ゆうパケットポスト（シール）、ゆうパケットポスト（専用箱）、ゆうパケット）
  - 中型（宅急便コンパクト、ゆうパケットプラス）
  - 大型（宅急便 / ゆうパック 60〜170サイズ）
  - その他・普通郵便（定形郵便 2024年10月新料金110円、定形外郵便、自由入力）
  - 専用箱（コンパクト70円、ゆうパケットプラス65円、ゆうパケットポスト専用箱65円等）やシール（ゆうパケットポストシール7.5円）などの**梱包資材費を自動加算**
- **アラート＆ビジュアル内訳**:
  - 最低出品価格（300円）未満アラート
  - 赤字（手残りマイナス）時の警告バナー
  - 手残り・手数料・送料・資材費の割合を示すカラーバー＆内訳リスト
- **出品メモ・履歴保存機能**:
  - 品名メモをつけてブラウザ（LocalStorage）に保存
  - ワンタップで以前の計算内容を再呼び出し・復元可能
- **ワンタップ結果コピー**:
  - 出品価格・手数料・送料・資材費・手残りをクリップボードにコピー

## 技術構成

- 単一HTMLファイル（HTML5 + CSS3 + Vanilla JavaScript）
- 外部CDNや依存ライブラリなし（完全オフライン動作可能）
- モバイルファースト・レスポンシブデザイン（タッチターゲット44px以上、iOS自動ズーム防止対応）
